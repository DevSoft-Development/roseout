# Enterprise Admin Module Ownership

- CRM owns account relationship, owner contacts, outreach, sales stage, and follow-up.
- Location Workspace owns profile data, menu, operations, growth tools, communication history, activity, and settings.
- Reserve owns live service operations and reservation-domain analytics.
- Growth owns campaigns, reviews, offers, VIP capture, and acquisition analytics.
- Platform owns production readiness, deployments, cron jobs, logs, permissions, billing configuration, and system settings.

Shared search, tasks, notifications, status vocabulary, and activity events must be provided through common services rather than copied into individual modules.
